# Third-party notices

## ReaxFF parameter file

The file `ffield.reax.choSiC.txt` used in the simulations is a third-party
ReaxFF parameter set. Its redistribution terms have not been confirmed.
Consequently, the parameter file is not included in this repository.

Users must obtain the parameter file from the original source and comply with
its terms. The data author identifies the following publication as the
reference associated with the ReaxFF parameter set:

> G. Li, F. Zheng, Q. Huang, J. Wang, B. Niu, Y. Zhang, D. Long,
> Molecular insight into pyrolysis processes via reactive force field
> molecular dynamics: A state-of-the-art review,
> Journal of Analytical and Applied Pyrolysis 166 (2022) 105620.
> https://doi.org/10.1016/j.jaap.2022.105620

The publication is cited here as the reference supplied by the data author.
It should not be represented as the original parameterization paper unless
that provenance is independently confirmed.
