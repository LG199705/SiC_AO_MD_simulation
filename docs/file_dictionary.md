# File dictionary

## Case-level input and structure files

| File | Role | Notes |
|---|---|---|
| `combin.lmp` | LAMMPS input script | Reads `anne.data`, applies the ReaxFF potential, minimises the structure, performs the AO bombardment run, and writes `deposit.data`. |
| `ffield.reax.choSiC.txt` | ReaxFF parameter file | Third-party parameter file. It is not included in this repository because redistribution terms are unresolved; see `THIRD_PARTY_NOTICES.md`. |
| `anne.data` | Initial equilibrated structure | 5,824 atoms and 2 atom types in the files inspected. The seven case copies are byte-identical. |
| `Mini.data` | Minimised structure | 5,824 atoms and 3 atom types in the files inspected. The seven case copies are byte-identical. It is generated by `combin.lmp`. |
| `deposit.data` | Final structure | Written at production step 400,000. Atom counts differ between cases and are lower than the initial count in several cases; confirm that each file represents the complete final system. |

## Files generated by `combin.lmp`

| File | Generating command | Status in current source archive |
|---|---|---|
| `Mini.lammpstrj` | `dump 1 all custom 100 Mini.lammpstrj ...` | Not present in the inspected case directories. |
| `bomb.lammpstrj` | `dump bomb_dump all custom ... bomb.lammpstrj ...` | Present only in `SiCCombin40AOps`; not included in this GitHub repository. |
| `norm_mass.txt` | `fix out_norm all print 100 ... file norm_mass.txt` | Not present in the inspected case directories. |
| `log.lammps` | LAMMPS `-log log.lammps` command | Not present in the inspected case directories. |

## Trajectory columns

`bomb.lammpstrj` uses the LAMMPS custom dump format with the following columns:

```text
id type x y z vx vy vz q c_1[2]
```

`c_1[2]` is the second component of the per-atom `ave/sphere/atom` quantity
defined in `combin.lmp`.

## Units

The simulations use LAMMPS `real` units. Coordinates are in Angstrom, time is
in femtoseconds, and the production time step is 0.25 fs.

## Duplicate files

The following files are byte-identical across all seven case directories:

- `anne.data`
- `Mini.data`
- `ffield.reax.choSiC.txt`

`anne.data` and `Mini.data` are retained in every case directory because
`combin.lmp` refers to them by relative path. `ffield.reax.choSiC.txt` is not
included in this repository and must be obtained separately.
